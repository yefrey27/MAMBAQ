## Flujo de Trabajo en GitHub

El proyecto siguió un flujo de trabajo con ramas para organizar el desarrollo:

```
main
 └── desarrollo de features
      ├── feature/efectos-canvas
      ├── feature/supabase-integration
      └── feature/kids-page
```

## Cómo Ver las Contribuciones

En GitHub puedes ver las contribuciones individuales en:

- **Insights → Contributors** — gráfica de commits por persona
- **Commits** — historial completo con autor de cada cambio
- **Pull Requests** — revisiones de código entre el equipo
